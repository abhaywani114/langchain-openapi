# langchain-openapi Documentation

Welcome to the documentation directory for `langchain-openapi`.

## Overview

This directory holds the source files for project documentation, guides, and API reference material.

## Contents

* [Architecture Specification](../ARCHITECTURE.md) - Detailed breakdown of the planned library architecture.
* [Roadmap](../ROADMAP.md) - Milestone tracking from foundation to v1.0 release.
* [Contributing Guide](../CONTRIBUTING.md) - Setup instructions for local development, linting, and testing.

## Planned Documentation Structure

As the library features are implemented, full technical documentation will be expanded into:

1. **Getting Started**: Quickstart guides and installation steps.
2. **Core Concepts**: Explanation of OpenAPI schema parsing, model mapping, and tool generation.
3. **API Reference**: Detailed module auto-generated docs for public classes and methods.
4. **Security & Authentication**: How to manage secrets and auth headers safely with generated tools.
