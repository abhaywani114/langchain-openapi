# langchain-openapi Examples

This directory will contain usage examples and demonstration scripts for `langchain-openapi`.

> **Note:** The library is currently at Milestone 1 (Project Foundation). Feature examples will be added as upcoming milestones (OpenAPI parser, LangChain tool generator, HTTP executor, etc.) are implemented.

## Planned Examples

* **Basic OpenAPI Tool Generation**: Loading a simple Petstore OpenAPI spec and creating LangChain tools.
* **Authentication Configurations**: Demonstrating API Key, OAuth2, and Bearer token authentication workflows.
* **Custom Tool Filtering**: Selecting specific endpoints or tags for tool generation.
* **Structured Input Schema Conversion**: Working with complex request bodies and parameter validation.
* **LangChain Agent Integration**: Binding OpenAPI-generated tools directly to an agent execution loop.

Check back in future releases as milestones are completed!
